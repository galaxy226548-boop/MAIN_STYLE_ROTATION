> 目标：为制作1小时、40页以上实习答辩PPT提供制作规范

## 一、各材料整体章节结构分析

### 1. 邱泓韬（106页）—— 最高参考权重

**结构模式：三模块并列型（Multi-Module）**

```
封面（1页）
目录（1页）—— 清晰列出三个研究模块 + 每个模块一句话概括贡献
─────────────────────────────────────────────────────
Part 1：基于股票关联和相似度的因子挖掘（约35页）
    ├── 章节封面：标题 + 核心成果数字 bullets（1页）
    ├── 研究动机：Lead-Lag效应经济机制 + 文献演进时间线（2页）
    ├── 方法论：因子三维框架解构（度量×算子×指标）（3页）
    ├── 实验流程：Step1-4 + 核心成果数字看板（1页）
    ├── 相似度矩阵构建细节（2页）
    ├── 因子筛选结果：按度量分类展示（6页）
    ├── 深度分析：独立Alpha vs 增强替代（4页）
    └── 子样本稳健性验证（2页）

Part 2：基于股票关联特征的深度学习预测网络（约30页）
    ├── 章节封面
    ├── 模型架构图（HIST模型）
    ├── 代码改进清单（数据/GPU/内存）
    ├── 特征选择逻辑（因子表格）
    ├── 实验设置（滚动窗口/超参数表）
    ├── 实验结果（IC/收益对比图表）
    └── 消融实验

Part 3：智能投研Agent深度基本面分析（约30页）
    ├── 章节封面
    ├── 系统架构图
    ├── 知识库7模块详解（逐模块）
    ├── 分析维度介绍（买方视角8维度）
    └── 完整案例：东方电缆（估值/竞争/投资结论）
─────────────────────────────────────────────────────
附录：因子分布图、子样本分析、估值细节
```

**关键结构特征：**
- 目录页用一句话提炼每个模块的核心贡献数字（不是简单列题目），如"系统性遍历72,450因子组合，发现三层独立Alpha结构"
- 每个Part有独立的"核心发现汇总页"，把全部结果浓缩在一张页里，位置在详细展示之前——先给评委一个全局印象，再展开细节
- 代码/工程部分单独成块（代码改进一、二……），不回避工程量
- 附录厚实，把所有验证性内容（稳健性检验、参数敏感性、完整案例细节）放附录，保持主体流畅

### 2. DREAM_Final（40页）—— 行业配置双模型框架

**结构模式：双轨并行型（Core + Satellite）**

```
封面（1页）
目录（1页）—— 6部分
─────────────────────────────────────────────────────
第一部分：研究背景（3页）
    ├── 市场背景：行业异步性中枢上移数据图
    ├── 当前挑战：三个核心问题（异构/摩擦/窗口）
    └── 研究方法与目标：研究问题+研究目标+开发边界

第二部分：模型框架（2页）
    ├── 模型思路（逻辑推导）
    └── 框架全景图（核心图，贯穿全文）

第三部分：择时卫星星座构建（9页）
    ├── 估值卫星（原理+改进+回测）
    ├── 泡沫卫星（LPPLS原理+回测）
    ├── 信用卫星 / 汇率卫星 / 地缘卫星
    └── 五维综合卫星结果

第四部分：截面轮动核心架构（8页）
    ├── 交易行为 / 技术指标 / 资金流 / 景气度 / 宏观驱动
    └── 五因子相关性矩阵+综合结果

第五部分：双擎融合及回测（8页）
    ├── 融合方式说明
    ├── 消融实验结果
    ├── 交易成本检验
    ├── 参数鲁棒性检验
    ├── 交互效应拆解
    └── 融合方案调整（5进N对比）

第六部分：总结展望（2页）
附录（5页）：参考文献、信号跟踪、Barra归因
```

**关键结构特征：**
- 双模块之间有"融合"章节专门处理两者叠加，不是简单叠加，有交互效应拆解
- 每个子因子都经过：原理→改进逻辑→单因子回测图表 的三段结构
- 鲁棒性检验独立成页，覆盖参数敏感性、数据滞后敏感性、子样本稳定性

### 3. 黄文晓（40页）—— 股指期货因子+Lasso择时

**结构模式：因子体系型（Factor-First）**

```
封面（1页）
目录（1页）—— 3部分

第一部分：研究框架与目标（7页）
    ├── 研究背景（市场痛点+期货适配性）
    ├── 研究方法（因子+模型+策略）
    ├── 工作流设计（fh系统CLI说明）
    └── 数据洞察（日频EDA+分钟EDA各1页）

第二部分：策略介绍（26页）
    ├── 因子类别概览（1页）
    ├── 日频因子1：反转因子→改进1→改进2（3页）
    ├── 日频因子2：量价相关（1页）
    ├── 日频因子3：持仓量（1页）
    ├── 分钟因子：日内动量理念（2页）
    ├── 分钟因子：日内反转+切割方式（4页）
    ├── 分钟因子：资金流+切割方式（3页）
    ├── 分钟因子：特异性收益+切割方式（3页）
    ├── 因子间相关性矩阵（1页）
    ├── 因子库绩效表（1页）
    └── Lasso训练（3页）

第三部分：总结展望（2页）
```

**关键结构特征：**
- 每个因子展示"原始版本图→改进逻辑→改进后图"，形成对比叙事，量化改进效果（夏普从0.16→0.31→1.01）
- 分钟因子采用"切割"逻辑组织，每类因子都有2-3页：基础→时间切割→成交量切割→低相关切割，结构统一，易于复制
- 因子库绩效页用大表格集中展示，方便对比，页尾有结论句

### 4. 顾诺（60页）—— 宽基指数短线择时

**结构模式：故事驱动+渐进揭示型**

```
封面（1页）
目录（1页）—— 4部分（含回测独立为第三部分）

第一部分：研究背景（10页）
    ├── 情境化开场：特斯拉持有158% vs 择时2633%（3页）
    ├── 择时三问（是什么/为什么/怎么做）
    └── 行情演绎四阶段框架（概念图）+ 研究方法+流程

第二部分：策略介绍（约30页）
    ├── 短期：日内动量/振幅/价格动量（含单指标回测）
    ├── 中期：分歧度和流动性（含组合回测）
    └── 长期：交易拥挤度（含组合回测）

第三部分：回测分析（约10页）
    ├── 复合策略最终结果
    ├── 分年度回测
    └── 样本内外对比

第四部分：总结展望（2页）
```

**关键结构特征：**
- 开场用"情境+数字冲击"：先问"你想翻一番吗？"，展示持有158%，再问"你想翻十倍吗？"，展示择时2633%——用3页建立研究动机，情绪感染力强
- 回测独立为第三部分，而不是附在策略介绍后，突出回测的独立地位
- 每个子策略页末有单指标回测结果（胜率/盈亏比/年均交易次数），格式统一

## 二、各材料信息密度分析

| 材料 | 平均每页字数估计 | 图表密度 | 信息密度特征 |
|------|----------------|----------|------------|
| 邱泓韬 | 高（300-500字） | 中（约40%页面有图） | 技术细节完整，公式+代码+表格+图并存 |
| DREAM | 中（200-350字） | 高（约60%页面有图） | 图文各半，逻辑图/框架图偏多 |
| 黄文晓 | 中低（150-300字） | 极高（约70%页面有图） | 图>文，每页核心是一张回测图+简短解读 |
| 顾诺 | 中（200-300字） | 高（约60%页面有图） | 前期文字重（概念建立），后期图重（结果展示） |

**规律总结：**
- 方法/原理页：文字密度高，配辅助示意图（如公式+流程图）
- 结果页：图为主，文字只写"核心观点"一句话 + 要点bullets（3-4条）
- 对比改进页：左图（改进前）→ 右图（改进后）+ 中间数字对比（如"夏普从0.16→1.01"）

## 三、标题写法分析

### 三种标题类型的使用分布

**主题式标题**（章节标题/大类标题）
- "第一部分 研究框架与目标"
- "2.2 分钟因子 - 日内资金流"
- "5.1 双参照模型回测及消融实验"

**结论式标题**（核心内容页）—— 最值得学习
邱泓韬大量使用，点明当页要传递的核心信息，而不只是告诉听众"我在讲什么"：
- "关联股票之间存在显著的收益率可预测性"（结论）vs "关联股票的研究背景"（主题）
- "同类动量溢出——与关联动量最高度相关的 Alpha 结构"
- DREAM："截面强度≠交易质量"（点明悖论）

黄文晓也用结论式副标题：
- "2.1 日频因子1 - 动量因子改进1"，加副标题"用close/vwap代替close/open"，把改进逻辑放在标题里

**问题式标题**（顾诺开场）
- "你想让你的资金在半年内翻一番吗？"
- "你想让你的资金在半年内变成10倍吗？"

**推荐写法：层级标题系统**
```
一级标题（章节）：主题式  例："第二部分 策略介绍"
二级标题（小节）：主题式  例："2.3 分钟因子 - 资金流切割"
页内核心声明：结论式      例："通过持仓量切割，夏普从-0.07提升至1.44"
```

## 四、图表与文字比例分析

**邱泓韬的比例策略：**
- 背景/动机页：文字占60%（时间线、经济机制说明）
- 方法论页：图文各50%（公式 + 流程示意图）
- 结果页：图占70-80%（IC散点图/因子分布图），文字是"核心观点"+解读bullets
- 工程页（代码改进）：以代码对比block为主，几乎无图

**DREAM的比例策略：**
- 框架图页（第9页）：占满整页的框架图，文字仅在左侧3-4个bullet点
- 每个卫星页：左侧原理表格/公式（40%），右侧回测曲线图（60%）
- 回测结果汇总页：多图并列，减少文字

**黄文晓的比例策略：**
- 改进对比页：固定两列布局，左图+右图，中间一列数字对比，文字极少
- 因子绩效表页：几乎全是表格，底部一行结论句

**顾诺的比例策略：**
- 开场3页：纯文字+一张指数图，情绪铺垫用
- 策略介绍：每个指标2页，第一页文字+定义，第二页回测图+胜率数字

**综合建议：图表占比应随章节进展提升**
```
背景章节：文字60% + 图40%（市场数据图、时间线）
方法章节：文字50% + 图50%（流程图、公式、架构图）
结果章节：文字20% + 图80%（回测曲线、绩效表、对比图）
总结章节：文字50% + 图50%（回顾框架图+关键数字）
```

## 五、方法→结果→结论的衔接方式

### 模式一：邱泓韬的"先汇总后细节"模式（推荐）

```
核心发现汇总页（先讲答案）
  ↓
Step 1：方法细节（为什么这样构建）
  ↓
Step 2：扩展方法
  ↓
Step 3：实验结果图表
  ↓
Step 4：稳健性验证
```
优点：评委在进入细节前就知道结论是什么，不会在细节中迷失。

### 模式二：DREAM的"原理→改进→回测"三段式（每个子因子适用）

```
因子原理说明（为什么这个变量有效）
  ↓
改进逻辑（为什么原始版本不够好，如"2022年后失效图"）
  ↓
改进后回测结果（量化改进幅度：年化/Sharpe/MDD）
```

### 模式三：黄文晓的"视觉对比衔接"（改进页）

```
左侧：原始因子图（Sharpe=0.16，ic=1.37%）
  ↓ 中间：改进逻辑文字box（1-2句）+ 箭头
右侧：改进后因子图（Sharpe=0.31，ic=2.93%）
```
这种方式不需要评委读文字，数字对比直接传达进步幅度。

### 模式四：顾诺的"叙事悬念驱动"（开场适用）

```
提出挑战（"你想翻一番吗？"）
  ↓
给出普通解答（持有=158%）
  ↓
升级挑战（"你想翻10倍吗？"）
  ↓
给出策略解答（择时=2633%）
  ↓
引出研究问题
```

## 六、值得模仿的页面设计和叙事方式

### 设计层面

**1. 框架全景图页（DREAM第9页）**
在第二章放一张覆盖全部架构的系统图，之后每介绍一个模块都可以在这张图上"点亮"对应部分，让评委始终知道身在何处。这是大型答辩PPT的核心导航工具。

**2. 核心成果数字看板（邱泓韬第7页）**
用4-6个数字卡片排列展示最强结果，如"最强单因子|RankIC| 12.16%"、"挖掘规模 72,450"，视觉冲击力强，适合在每个Part结尾或开头使用。

**3. 时间线演进图（邱泓韬第4页）**
文献综述不写文字列表，改为横向时间线，每个节点一行：年份+论文+核心贡献，信息密度高且视觉整洁。

**4. 因子绩效大表（黄文晓第31页）**
所有因子集中在一张表格，列：因子名/Sharpe/ann_ret/max_dd/calmar/tvr/ic，底部一句总结。这种"一表尽览"设计让评委可以自行比较，不需要逐页翻看。

**5. 改进前后左右对比页（黄文晓第13、14、22页）**
固定布局：左图（原始）→中间改进文字→右图（改进后），是展示迭代改进最清晰的方式。

**6. 章节入场页（各材料统一用）**
每个章节开始用一页"章节封面"，展示本章子标题列表。顾诺最简洁（纯文字3-4行），黄文晓最规范（方框+编号+小标题），都有效果。

### 叙事层面

**7. 开场情境化（顾诺）**
用1-3页具体场景引入，不直接进入"研究背景"，而是先让评委感受到"这个问题值得研究"。适合第一页开始后的1-2分钟。

**8. 经济机制先于数学（各材料通用）**
所有材料在给出公式之前，先用一段话说"为什么这样做是有道理的"。如黄文晓：先说"VWAP反映大量资金真实参与后的价格中枢"，再给公式。

**9. 负面结果不回避（DREAM，邱泓韬）**
DREAM专门展示"2022年后原指标失效图"，邱泓韬展示"尝试过但效果差的方向"。这体现了研究的诚实性，也让改进显得更有说服力。

**10. 用"→"符号做逻辑串联**
各材料大量使用"A → B → C"的视觉箭头串联因果关系，比文字句子更清晰直接。例如：
"散户跟随效应时滞 → 板块内资金流领先/滞后 → 构建资金流偏离因子"

## 七、制作规范：适合1小时、40页以上实习答辩PPT

### 1. 总体规格

| 维度 | 建议规格 |
|------|---------|
| 总页数 | 42-50页（主体）+ 10-15页附录 = 55-65页 |
| 时长 | 约50-55分钟（每页约1-1.5分钟，结果页更快，框架页更慢） |
| 比例控制 | 主体不超过55页，超出的内容放附录 |

### 2. 章节比例建议

```
封面+目录            2页    （约2分钟）
研究背景与动机        4-5页  （约5分钟）
研究框架/系统架构     2-3页  （约4分钟）
核心方法1            8-10页  （约12分钟）
核心方法2            8-10页  （约12分钟）
[核心方法3，如有]     6-8页  （约9分钟）
融合/综合结果         3-4页  （约5分钟）
总结展望              2页    （约3分钟）
────────────────────────────
附录                 10-15页 （备用，Q&A时翻阅）
```

### 3. 每页信息密度规范

**背景/动机页**（每章开头2-3页）
- 核心内容：1个核心观点 + 1张支撑图/数据 + 3-5个bullet解读
- 字数上限：正文不超过200字
- 图表：1张市场数据图，或1张时间线/框架图

**方法/原理页**（每个子模块1-2页）
- 核心内容：经济逻辑（1-2句）+ 公式/定义 + 与已有方法的区别
- 字数上限：150字（不含公式符号）
- 图表：流程示意图或对比表格

**结果页**（每个子模块1-2页）
- 核心内容：核心观点标题（1句结论式）+ 图表为主 + 解读bullets（3-4条）
- 字数上限：100字（不含图注）
- 图表：占页面60%-80%，以回测曲线图、绩效表为主

**对比改进页**（展示迭代时使用）
- 布局：左图（原始）+ 中间改进逻辑（box）+ 右图（改进后）
- 核心元素：改进前后关键数字对比（如"Sharpe: 0.31 → 1.01"）
- 字数上限：80字（改进逻辑说明）

**总结页**
- 核心内容：回顾架构图 + 分点列核心结论（每点一行）+ 改进方向
- 字数上限：200字

### 4. 图表风格规范

- **颜色体系**：使用两种主色（蓝色系+橙色系，如广发基金风格），结果图配色与主题色统一
- **回测曲线图**：必须标注训练集/测试集分割线（红色虚线），标注关键时间节点
- **绩效指标**：统一在图例框内展示 Sharpe/年化收益/IC/换手率，不散落文字中
- **对比图**：改进前用冷色系（蓝/灰），改进后用暖色系（橙/红），视觉区分明显
- **表格**：表头深色底白字，数据行隔行浅灰，关键数字加粗或加底色
- **公式**：使用标准数学排版，公式后紧跟参数说明表格（变量/含义两列）

### 5. 标题写法规范

```
章节封面标题：   主题式，简洁  例："策略介绍"
小节标题：       "编号 主题 - 副主题"  例："2.3 分钟因子 - 资金流切割"
结果页页眉：     结论式，一句话  例："通过持仓量切割，夏普从−0.07提升至1.44"
图表标题：       描述性  例："Lasso模型因子权重分布（非负约束，多品种池化）"
```

### 6. 特殊页面必须包含的元素

**"核心成果汇总页"**（每个大模块开头或结尾各一页）
- 格式：4-6个数字卡片 + 3-4行流程描述
- 时机：在展开细节之前，先给出全局印象

**"框架全景图页"**（答辩PPT第3-4页，仅一页）
- 内容：整个研究/系统的结构图，展示各模块关系
- 要求：之后每次进入新模块，可以引用/标注这张图

**"稳健性检验页"**（每个核心结果后，附录或主体均可）
- 内容：样本外表现、参数敏感性、子样本分析
- 最少：样本内外Sharpe对比表 + 逐年回测结果

**"改进方向页"**（总结章节）
- 格式：现有结论（3条，诚实列出局限性）+ 后续优化方向（3条，具体可执行）
- 避免：只说"未来继续研究"之类的空话

### 7. 答辩节奏建议（1小时对应结构）

```
0-5分钟    封面+目录+研究背景（直接建立重要性，顾诺式情境开场效果好）
5-10分钟   整体框架介绍（放全景图，交代本次答辩的三条主线）
10-25分钟  核心方法1详细介绍（方法+结果+稳健性）
25-40分钟  核心方法2详细介绍
40-50分钟  综合结果/融合/对比实验
50-55分钟  总结与展望（诚实的结论+具体改进方向）
55-60分钟  Q&A（附录备用）
```

### 8. 禁止事项（从参考材料中总结的负面案例）

- ❌ 每页超过500字（正文）——评委不会读，视觉压迫感强
- ❌ 结果图表不标注样本内外分割线——无法判断过拟合风险
- ❌ 标题只写主题不写结论——浪费最显眼的视觉位置
- ❌ 因子改进只展示改进后，不展示改进前——缺乏对比，说服力弱
- ❌ 方法细节超过结果细节——答辩重点在结果，方法说清楚即可
- ❌ 没有附录——评委提问没有材料可翻
- ❌ 回测绩效不报告最大回撤和换手率——Sharpe单指标不足以评估策略
