# 模块函数清单与功能说明

本文按目录梳理当前已拆分文件中的函数、主要输入输出、核心功能，以及是否依赖全局变量或配置。说明只覆盖当前模块化单因子回测框架，不包含旧主脚本中的全部历史因子生成代码。


## 1. `config/`

### `config/single_factor_config.py`

| 对象 | 输入 | 输出 | 功能 | 依赖 |
|---|---|---|---|---|
| `SingleFactorConfig` | 构造参数 | 不可变配置对象 | 保存单因子回测所需参数 | `dataclasses.dataclass`, `Path` |
| `OW_F001_CN10Y_Q3Y` | 无运行时输入 | `SingleFactorConfig` 实例 | 当前默认单因子配置 | `PROJECT_ROOT` |

字段说明：

| 字段 | 功能 |
|---|---|
| `raw_factor_col` | raw 因子列名 |
| `factor_name` | 正式因子列名 |
| `bar` | 信号阈值 |
| `signal_type` | `state` 或 `event` |
| `benchmark_mode` | 基准模式 |
| `benchmark_rebalance_months` | 基准再平衡月份间隔 |
| `trans_fee` | 单边交易费率 |
| `charge_initial_trade` | 首期建仓是否收费 |
| `output_dir` | 输出目录 |

## 2. `data_io/`

### `data_io/loaders.py`

| 函数 | 输入 | 输出 | 功能 | 依赖 |
|---|---|---|---|---|
| `resolve_data_paths(project_root)` | 项目根目录 `Path` | `(data_path, market_path)` | 按根目录、`data_processed/`、`data/` 顺序查找 `data_df.parquet` 和 `market_df.parquet` | `Path` |
| `load_data_and_market(project_root)` | 项目根目录 `Path` | `data_df`, `market_df`, `data_path`, `market_path` | 读取并按索引排序基础数据表 | `pd.read_parquet`, `resolve_data_paths` |

## 3. `factors/`

### `factors/raw_loader.py`

| 函数 | 输入 | 输出 | 功能 | 依赖 |
|---|---|---|---|---|
| `ensure_raw_factor(data_df, raw_factor_col, project_root)` | `data_df`、raw 因子列名、项目根目录 | 带 raw 因子列的 `data_df` | 若 `data_df` 已有 raw 列则直接返回；否则从 `ow_factors_raw.parquet` 读取该列并按 `data_df.index` 对齐 | `pd.read_parquet`, `pd.to_datetime` |

注意：该函数不会临时生成因子。若 `data_df` 和 `ow_factors_raw.parquet` 都没有目标列，会抛出清晰错误。

## 4. `signals/`

### `signals/mount.py`

| 函数 | 输入 | 输出 | 功能 | 依赖 |
|---|---|---|---|---|
| `merge_factor_to_market(data_df, market_df, raw_factor_col, factor_type="state", track_col="track_id")` | 带 raw 因子的 `data_df`、基础 `market_df`、raw 因子列名、信号类型、轨道列名 | 挂载正式因子列后的 `market_df` | 将 `*_raw` 转为正式因子列并挂载到 `market_df` | `Config.FEATURE_LIST`, `Config.Tunnels`, `pd`, `np` |

核心逻辑：

| `factor_type` | 行为 |
|---|---|
| `state` | `data_df[factor_col] = data_df[raw_factor_col].shift(1)`，再按日期 reindex 到 `market_df` |
| `event` | 对每个事件日期，把事件值挂到每条轨道中事件日之后的首个可交易调仓点 |

### `signals/target_position.py`

| 函数 | 输入 | 输出 | 功能 | 依赖 |
|---|---|---|---|---|
| `build_state_target_position(track_df, factor_col, bar=0)` | 单条轨道 `track_df`、正式因子列名、阈值 | 增加目标仓位列的 `DataFrame` | 状态型信号转目标仓位 | `pd`, `np` |
| `build_event_target_position(track_df, event_col, event_time_col=None, bar=0)` | 单条轨道 `track_df`、事件列名、事件时间列、阈值 | 增加目标仓位列的 `DataFrame` | 事件型信号转目标仓位 | `pd`, `np` |

输出新增列：

| 列 | 含义 |
|---|---|
| `target_weight_g` | 成长目标权重 |
| `target_weight_v` | 价值目标权重 |
| `signal_ls` | 1=成长，-1=价值，0=中性/跟随基准，`NaN`=event 无新事件 |
| `signal_update_flag` | 1=本期更新信号，0=event 无新事件 |

## 5. `positions/`

### `positions/benchmark.py`

| 函数 | 输入 | 输出 | 功能 | 依赖 |
|---|---|---|---|---|
| `build_benchmark_rebalance_flag(track_index, rebalance_months)` | 单条轨道日期索引、再平衡月份间隔 | `pd.Series`，index 为轨道日期，值为 0/1 | 给单条轨道生成基准再平衡标记 | `pd.DateOffset` |

规则：第一行标记为 1；之后当当前日期达到上次再平衡日期 + `rebalance_months` 后，在首个可交易轨道点标记为 1。

## 6. `backtest/`

### `backtest/returns.py`

| 函数 | 输入 | 输出 | 功能 | 依赖 |
|---|---|---|---|---|
| `to_simple_return(ret_series, return_type=Config.RETURN_TYPE)` | 收益率序列、收益率口径 | simple return 序列 | 将 log return 或 simple return 统一转为 simple return | `Config.RETURN_TYPE`, `np.expm1`, `pd.Series` |

### `backtest/engine.py`

| 函数 | 输入 | 输出 | 功能 | 依赖 |
|---|---|---|---|---|
| `calc_pre_trade_actual_weight(prev_post_weight_g, prev_post_weight_v, prev_ret_g_simple, prev_ret_v_simple)` | 上期调仓后权重、上期成长/价值区间收益 | 本期调仓前成长/价值实际权重 | 根据资产涨跌计算权重漂移 | 无业务外部状态 |
| `weights_are_different(weight_g_a, weight_v_a, weight_g_b, weight_v_b, tol=weight_tol)` | 两组成长/价值权重、容忍度 | `bool` | 判断两组权重差异是否超过阈值 | 模块全局 `weight_tol` |
| `decide_post_trade_weight(...)` | 调仓前权重、本期信号、目标权重、上期有效信号、基准模式、接收方、基准引用行 | `effective_signal_ls`, `post_trade_weight_g`, `post_trade_weight_v`, `trade_flag`, `signal_count` | 决定本期是否交易、交易后仓位和有效信号 | `weights_are_different`, `pd.isna` |
| `run_single_track_backtest(track_target_df, benchmark_mode, trans_fee, charge_initial_trade, receiver, benchmark_ref_track_df=None)` | 单轨目标仓位表、费用和基准参数、接收方、可选同轨基准结果表 | 单轨区间回测结果 `track_result_df` | 逐行递推权重、交易、费用、区间收益和有效信号 | `calc_pre_trade_actual_weight`, `decide_post_trade_weight`, 模块全局 `weight_tol` |

`run_single_track_backtest` 输出列包括：`track_id`、`next_date`、`signal_ls_raw`、`effective_signal_ls`、`signal_update_flag`、`pre_trade_weight_g/v`、`post_trade_weight_g/v`、`trade_flag`、`signal_count`、`turnover_2way`、`cost_rate`、`fwd_ret_g_simple`、`fwd_ret_v_simple`、`holding_days`、`period_ret_long_gross`、`period_ret_long_net`、`period_ret_ls`。

### `backtest/nav.py`

| 函数 | 输入 | 输出 | 功能 | 依赖 |
|---|---|---|---|---|
| `build_single_track_daily_nav(track_period_df, daily_asset_ret_df)` | 单轨区间回测结果、日频资产收益表 | 单轨日频 NAV `pd.Series` | 按调仓后权重重建逐日净值路径 | 模块全局 `n=10`, `pd`, `np` |

核心规则：首个调仓日先扣本期费用；持有区间使用 `(start_date, end_date]` 的日收益；到下一调仓日收盘后扣下一期费用并切换到下一期权重；允许最后 `n=10` 行 `next_date` 为 `NaT`。

### `backtest/metrics.py`

| 函数 | 输入 | 输出 | 功能 | 依赖 |
|---|---|---|---|---|
| `calc_annualized_return(ret_series, holding_days_series, annual_days=annual_days)` | 区间收益、持有天数 | 年化收益率 | 复利总收益后按持有天数年化 | `annual_days`, `np` |
| `calc_annualized_vol(ret_series, holding_days_series, annual_days=annual_days)` | 区间收益、持有天数 | 年化波动率 | simple return 转 log return，再按日均 log return 年化 | `annual_days`, `np` |
| `calc_max_drawdown(nav_series)` | NAV 序列 | 最大回撤正数 | 计算累计高点回撤 | `pd.Series` |
| `calc_sharpe_ratio(ret_series, holding_days_series, rf, annual_days=annual_days)` | 收益、持有天数、无风险利率 | 夏普比率 | 年化收益减无风险利率后除以年化波动 | `rf`, `annual_days` |
| `calc_information_ratio(excess_ret_series, holding_days_series, annual_days=annual_days)` | 超额收益、持有天数 | 信息比率 | 年化超额收益除以年化超额波动 | `annual_days` |
| `calc_monthly_win_rate(nav_series)` | NAV 序列 | 月度胜率 | 月末 NAV 计算月收益，统计正收益比例 | pandas resample |
| `calc_payoff_ratio(weekly_ret_series)` | 区间收益序列 | 盈亏比 | 正收益均值 / 负收益绝对均值 | `pd.Series` |
| `calc_calmar_ratio(annualized_return, max_drawdown)` | 年化收益、最大回撤 | 卡玛比率 | 年化收益 / 最大回撤 | `pd.isna` |
| `calc_market_regime_win_rate(track_result_df)` | 单轨结果表 | 成长波段胜率、价值波段胜率 | 在成长/价值分别跑赢的区间统计策略正收益比例 | `fwd_ret_g_simple`, `fwd_ret_v_simple`, `period_ret_long_net` |

### `backtest/summary.py`

| 函数 | 输入 | 输出 | 功能 | 依赖 |
|---|---|---|---|---|
| `build_track_summary_table(strategy_track_result_df, benchmark_track_result_df, strategy_track_nav, benchmark_track_nav, rf=rf, annual_days=annual_days)` | 单轨策略结果、单轨基准结果、单轨策略 NAV、单轨基准 NAV | 年度 + 全区间绩效表 | 汇总单轨绩效指标 | `backtest.metrics` 中各指标函数、`rf`, `annual_days` |

输出行：每个自然年份一行，最后一行为 `全区间`。输出列为 `trade_count`、`signal_count`、收益、波动、回撤、夏普、IR、月胜率、盈亏比、卡玛、换手、成长/价值波段胜率等。

## 11. 不能随意改变的函数

| 函数 | 原因 |
|---|---|
| `merge_factor_to_market` | 控制 state shift 和 event 分轨可得日，涉及未来函数风险 |
| `build_state_target_position` | 定义 state 的 NaN/0 语义 |
| `build_event_target_position` | 定义 event 的 NaN/0 和 carry 语义 |
| `decide_post_trade_weight` | 控制中性信号引用基准、event carry、调仓判断 |
| `run_single_track_backtest` | 单轨回测状态递推核心 |
| `build_single_track_daily_nav` | 费后日频 NAV 重建核心 |
