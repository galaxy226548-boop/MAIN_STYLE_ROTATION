# 风格定义

- 构建标的的必要性

    长江证券 250309：

    1. 现有指数筛选规则限制过多（如为提高收益，在成长指数中混入ROE、PCF等额外因子），导致风格不够纯粹，难以凸显单一风格收益；

    2. 样本容量或分位阈值约束机械，固定数量或绝对比例（如市值前50%）无法适应上市公司数量增长及风格内部的连续性细分；

        - 曾经小盘股代表通常使用中证500，现在对标用中证1000

    3. 样本空间限制复杂且调仓频率低（多为半年或季度），难以及时反映季报发布就会变化的基本面和每日更新的市值；

    4. 传统等权或市值加权方式易导致行业权重漂移，缺乏均衡性，需采用类A500的行业中性化配权，在不变更成分的情况下尽量使各行业成份权重与样本空间一致，行业内采用流通市值加权。

##### 风格趋势

- 对因子进行市值和行业中性化处理（因子对log\(市值\)和行业哑变量回归，取残差）

- 每周计算最新截面中性化因子与未来20个交易日个股收益率的rankIC

- 计算滚动52周的rankIC平均数和标准差，ICIR = rankIC的滚动52周平均数/rankIC的滚动52周标准差

- 对ICIR进行滚动六年窗口的zscore处理，得因子时序动量指标

##### 交易拥挤度

- 选定因子，按照因子值排序分为五组（行业中性，每个行业内分组后再合并），确定多头组和空头组

- 计算多头组和空头组的平均换手率、平均波动率和平均Beta

- 换手率比率 = 多头组平均换手率/空头组平均换手率，波动率比率和Beta比率同理

- 对换手率比率、波动率比率和Beta比率原始序列进行LLT\(30\)的平滑处理

    - 换手率为个股滚动三个月的换手率、波动率是个股滚动三个月的波动率、Beta是个股过去三个月对中证全指回归的Beta

- 对平滑后的换手率比率进行滚动六年窗口的zscore处理，即可得换手率比率zscore，同理得波动率比率zscore和beta比率zscore

- 交易拥挤度 =（换手率比率zscore\+波动率比率zscore\+beta比率zscore）/3

- **如果一个品种同时满足“高换手”、“高波动”和“高弹性”，则大概率处于拥挤交易中。**

##### 交易拥挤度

- 选定因子，按照因子值排序分为五组（行业中性，每个行业内分组后再合并），确定多头组和空头组

- 计算多头组和空头组的平均换手率、平均波动率和平均Beta

- 换手率比率 = 多头组平均换手率/空头组平均换手率，波动率比率和Beta比率同理

- 对换手率比率、波动率比率和Beta比率原始序列进行LLT\(30\)的平滑处理

    - 换手率为个股滚动三个月的换手率、波动率是个股滚动三个月的波动率、Beta是个股过去三个月对中证全指回归的Beta

- 对平滑后的换手率比率进行滚动六年窗口的zscore处理，即可得换手率比率zscore，同理得波动率比率zscore和beta比率zscore

- 交易拥挤度 =（换手率比率zscore\+波动率比率zscore\+beta比率zscore）/3

- **如果一个品种同时满足“高换手”、“高波动”和“高弹性”，则大概率处于拥挤交易中。**

- **动态宏观信号**

    - **信号构建方法：**

        1. 每月底对20个核心宏观因子的方向（t较t\-2期）进行判断。

        2. 设定每个宏观因子对“成长\-价值”超额收益的影响方向（见图表9）。

        3. 统计自宏观与指数数据均存在以来的该方向对次月超额收益的择时胜率。

        4. 每月底选择上月胜率大于55%的宏观因子，作为当月“动态宏观因子”。

            - **动态筛选宏观指标的优势在于能实时捕捉有效的指标，历史上不乏前期无效而后续有效、前期有效但逐步失效的指标。**

                - **例如，“美国2年期国债到期收益率”**在2018年之前对成长超额收益的择时效果较差，但2018年后有效性开始逐步提升，其背后的核心原因是2018年后中国金融开放提速叠加中国科技企业走向世界，A股成长风格受全球流动性影响愈发明显。

                - **再比如，“工业企业净利润增速”**对成长超额收益的择时有效性在2023年后逐步走低，于近期胜率跌至55%以下，其核心原因在于传统工业企业景气度对A股整体成长风格影响度在下降，且目前的高成长行业更聚焦于景气度的边际改善度而非绝对水平。

        5. 给出每个“动态宏观因子”的择时观点（1看多成长，\-1看多价值）。

        6. 加总第5步中得分总和（\&gt;0看多成长，\&lt;0看多价值，0延续上月信号）。

# 进一步尝试

- 涉及宏观指标的回归

    - IVX预测回归模型：解决“伪回归”问题

        - 构建一个特殊的工具变量

    - DLM动态线性模型：捕捉“动态变化”的关系

        - 将回归系数视为一个“隐藏状态”，允许它随时间变化。通过状态空间模型和卡尔曼滤波来估计每一时刻的动态系数

    - 3PRF三阶段回归滤波：“降维”合成指标

        - 把多个细分指标合成了**经济增长、资金面、通胀、市场情绪**四大类综合指标

        - 专注于寻找与预测目标协方差最大的组合

- 国泰君安 241102：

    - 一是宏观维度引入经济周期的思想。

        - 目前宏观维度简单地使用三个因子的趋势进行判断，较为粗糙。未来更加完善的做法是对当下所处的经济周期进行划分，从而判断大小盘风格较为长期的相对优势。再进一步，还可以将各个因子结合经济周期进行分段，即因子在不同周期下可能有不同的逻辑，从而进行更细致的分析。

    - 二是如何确定各维度权重，把握主线维度。

        - 目前对各维度信号进行等权汇总，但实际上有些维度不起主导作用，有些维度可能已经定价，在预测未来走势时需要找出真正起主导作用且未被充分定价的维度，赋予更高权重。

    - 三是如何在模型层面兼容“哑铃型策略”。

        - 目前的量化模型把标的资产作为Y，因子作为 X 去构造映射函数，无法兼容“哑铃型策略”这种两头配置的思路。未来如何在模型层面去实现这一效果，也是改进思路之一。
