# 单因子回测流程与数据框说明

本文说明当前模块化单因子回测入口 `scripts/run_single_factor.py` 的执行顺序、各步骤输入输出，以及核心 DataFrame / Series 的字段含义。说明以当前已验证的 `OW_F001_CN10Y_Q3Y` 单因子流程为准，不涉及多因子组合。

## 1. 执行总览

文件夹流程检查
config/	路径、全局参数、因子配置表
data_clean/	原始数据读取、日期/数值清洗、发布日对齐

signals/	state/event 信号规则、bar/方向映射
  __init__.py
  mount.py
  target_position.py
positions/	五轨信号挂载、目标仓位生成、benchmark target
  __init__.py
  benchmark.py
backtest/	单轨回测、NAV、绩效指标
  __init__.py
  returns.py
  engine.py
  nav.py

  __init__.py

|---:|---|---|---|---|---|
| 1 | `config/single_factor_config.py` | 无外部输入 | `OW_F001_CN10Y_Q3Y` 配置对象 | `SingleFactorConfig` | 提供 raw 因子名、正式因子名、阈值、信号类型、回测参数和输出目录 |

| 8 | `scripts/run_single_factor.py::build_strategy_target_df` | `work_df`, `track_list` | `strategy_target_df` | `pd.DataFrame` | 根据信号类型生成策略目标仓位 |

| 13 | `scripts/run_single_factor.py::save_outputs` | 核心结果表和组合 NAV | 输出文件 | parquet / csv | 保存到配置指定输出目录 |

## 2. 配置对象

### `SingleFactorConfig`

当前配置对象为 `OW_F001_CN10Y_Q3Y`。

| 字段 | 当前值 | 含义 |
|---|---|---|
| `raw_factor_col` | `OW_F001_CN10Y_Q3Y_raw` | `data_df` 中 raw 因子列名 |
| `factor_name` | `OW_F001_CN10Y_Q3Y` | 挂载到 `market_df` 后使用的正式因子列名 |
| `bar` | `0` | 信号转仓位阈值 |
| `signal_type` | `state` | 状态型信号，每个调仓点重新判断 |
| `benchmark_mode` | `rebalance_50` | 基准为定期再平衡到 50/50 |
| `benchmark_rebalance_months` | `2` | 基准每满 2 个月后的首个轨道可交易日再平衡 |
| `trans_fee` | `0.002` | 单边交易费率 |
| `charge_initial_trade` | `True` | 首期建仓收取交易费用 |
| `output_dir` | `output_regression/OW_F001_CN10Y_Q3Y_refactor_tmp` | 默认输出目录 |

## 3. 核心数据框与序列说明

### 3.1 `data_df`

- 生成位置：`data_io/loaders.py::load_data_and_market`
- 母数据：项目中的 `data_df.parquet`
- 行索引：交易日期，`DatetimeIndex`，升序
- 频率：日频交易日
- 作用：提供成长/价值价格和 raw 因子挂载底表

| 列 | 含义 |
|---|---|
| `close_g` | 国证成长指数收盘价 |
| `close_v` | 国证价值指数收盘价 |
| `pct_change_g` | 成长指数日涨跌幅，来自基础数据 |
| `pct_change_v` | 价值指数日涨跌幅，来自基础数据 |
| `OW_F001_CN10Y_Q3Y_raw` | raw 因子值；若原始 `data_df` 不含该列，则由 `factors/raw_loader.py` 从 `ow_factors_raw.parquet` 读取并按日期 reindex |

### 3.2 `market_df`

- 生成位置：`data_io/loaders.py::load_data_and_market`
- 母数据：项目中的 `market_df.parquet`
- 行索引：交易日期，`DatetimeIndex`，升序
- 频率：五轨调仓点对应的日频表
- 作用：承载五轨轨道、未来持有区间收益和目标收益

| 列 | 含义 |
|---|---|
| `track_id` | 五轨编号，通常为 0/1/2/3/4 |
| `fwd_ret_g` | 当前调仓日至下一同轨调仓日的成长指数收益，口径由 `Config.RETURN_TYPE` 决定 |
| `fwd_ret_v` | 当前调仓日至下一同轨调仓日的价值指数收益，口径由 `Config.RETURN_TYPE` 决定 |
| `holding_days` | 当前同轨持有区间天数 |
| `target_return_diff` | `fwd_ret_g - fwd_ret_v`，未来一期成长相对价值收益差 |
| `target_label` | `target_return_diff` 的方向标签，成长跑赢通常记为 1，否则为 0 |
| `next_date` | 下一次同轨调仓日期；每条轨道末尾可能为 `NaT` |
| `close_g` | 当前日期成长指数收盘价 |
| `close_v` | 当前日期价值指数收盘价 |
| `OW_F001_CN10Y_Q3Y` | 正式因子列，由 `merge_factor_to_market` 从 raw 因子挂载得到 |

### 3.3 `market_df_all`

- 生成位置：`scripts/run_single_factor.py::main`
- 母数据：已挂载正式因子列的 `market_df`
- 行索引：交易日期
- 过滤条件：`Config.ALL_START <= market_df.index <= Config.ALL_END`
- 作用：全样本回测区间底表

### 3.4 `work_df`

- 生成位置：`scripts/run_single_factor.py::build_work_df`
- 母数据：`market_df_all`
- 行索引：交易日期
- 过滤条件：`market_df_all.index > factor_available_date`
- 作用：策略和基准目标仓位生成的统一底表

| 列 | 含义 |
|---|---|
| `track_id` | 五轨编号 |
| `OW_F001_CN10Y_Q3Y` | 正式因子值 |
| `fwd_ret_g` | 成长指数当前持有区间收益，原始口径 |
| `fwd_ret_v` | 价值指数当前持有区间收益，原始口径 |
| `holding_days` | 当前持有区间天数 |
| `target_return_diff` | 成长 - 价值未来一期收益差 |
| `next_date` | 下一同轨调仓日 |
| `target_label` | 成长是否跑赢价值的标签 |
| `close_g` | 当前日期成长指数收盘价 |
| `close_v` | 当前日期价值指数收盘价 |
| `fwd_ret_g_simple` | `fwd_ret_g` 转换后的简单收益率 |
| `fwd_ret_v_simple` | `fwd_ret_v` 转换后的简单收益率 |
| `fwd_ret_diff_simple` | `fwd_ret_g_simple - fwd_ret_v_simple` |

### 3.5 `strategy_target_df`

- 生成位置：`scripts/run_single_factor.py::build_strategy_target_df`
- 母数据：`work_df`
- 行索引：交易日期
- 生成逻辑：逐 `track_id` 调用 `signals/target_position.py::build_state_target_position`
- 作用：策略侧目标仓位表，输入给单轨回测器

| 列 | 含义 |
|---|---|
| `track_id` | 五轨编号 |
| `OW_F001_CN10Y_Q3Y` | 当前调仓点可用的正式因子值 |
| `fwd_ret_g`, `fwd_ret_v` | 当前持有区间成长/价值收益，原始口径 |
| `holding_days` | 当前持有区间天数 |
| `target_return_diff` | 成长 - 价值未来一期收益差 |
| `next_date` | 下一同轨调仓日 |
| `target_label` | 成长是否跑赢价值标签 |
| `close_g`, `close_v` | 当前日期成长/价值收盘价 |
| `fwd_ret_g_simple`, `fwd_ret_v_simple`, `fwd_ret_diff_simple` | simple return 口径收益列 |
| `target_weight_g` | 成长指数目标权重，取值通常为 0/0.5/1 |
| `target_weight_v` | 价值指数目标权重，取值通常为 0/0.5/1 |
| `signal_ls` | 目标方向：1=全仓成长，-1=全仓价值，0=跟随基准/中性 |
| `signal_update_flag` | 状态型信号恒为 1；事件型无新事件时为 0 |

状态型语义：`factor > bar` 看好成长；`factor < -bar` 看好价值；`factor` 在阈值内或 `NaN` 时为 `signal_ls=0`，后续由回测器引用基准仓位。

### 3.6 `benchmark_target_df`

- 生成位置：`scripts/run_single_factor.py::build_benchmark_target_df`
- 母数据：`work_df`
- 行索引：交易日期
- 生成逻辑：固定 50/50，逐轨生成基准再平衡标记
- 作用：基准侧目标仓位表，同时在策略 `signal_ls=0` 时为策略提供基准仓位引用

| 列 | 含义 |
|---|---|
| `track_id` | 五轨编号 |
| `OW_F001_CN10Y_Q3Y` | 同期正式因子值，仅保留便于对齐检查 |
| `fwd_ret_g_simple` | 成长指数当前持有区间 simple return |
| `fwd_ret_v_simple` | 价值指数当前持有区间 simple return |
| `holding_days` | 当前持有区间天数 |
| `next_date` | 下一同轨调仓日 |
| `target_weight_g` | 基准成长目标权重，固定为 0.5 |
| `target_weight_v` | 基准价值目标权重，固定为 0.5 |
| `signal_ls` | 基准方向，固定为 0 |
| `signal_update_flag` | 基准是否再平衡；首期为 1，`rebalance_50` 下满指定月数后的首个可交易点为 1，否则为 0 |

### 3.7 `strategy_period_df`

- 生成位置：`scripts/run_single_factor.py::run_period_backtests`
- 母数据：`strategy_target_df`
- 行索引：交易日期
- 生成逻辑：逐轨调用 `backtest/engine.py::run_single_track_backtest` 后拼接
- 作用：策略侧单轨区间回测结果表

| 列 | 含义 |
|---|---|
| `track_id` | 五轨编号 |
| `next_date` | 当前区间结束日期，即下一同轨调仓日 |
| `signal_ls_raw` | 目标仓位表中的原始 `signal_ls` |
| `effective_signal_ls` | 本期实际生效方向；无新事件时可能沿用上一期 |
| `signal_update_flag` | 本期是否有新状态/新事件或基准再平衡标记 |
| `pre_trade_weight_g` | 本期调仓前成长实际权重 |
| `pre_trade_weight_v` | 本期调仓前价值实际权重 |
| `post_trade_weight_g` | 本期调仓后成长权重 |
| `post_trade_weight_v` | 本期调仓后价值权重 |
| `trade_flag` | 本期是否发生调仓，1=调仓，0=不调仓 |
| `signal_count` | 本期是否收到信号；状态型有值时通常为 1 |
| `turnover_2way` | 双边换手率 |
| `cost_rate` | 本期交易成本率，`turnover_2way * trans_fee`，首期是否收费由配置控制 |
| `fwd_ret_g_simple` | 成长当前区间 simple return |
| `fwd_ret_v_simple` | 价值当前区间 simple return |
| `holding_days` | 当前持有区间天数 |
| `period_ret_long_gross` | 费前多头组合区间收益 |
| `period_ret_long_net` | 费后多头组合区间收益，`(1 - cost_rate) * (1 + gross) - 1` |
| `period_ret_ls` | 多空方向收益，`effective_signal_ls * (fwd_ret_g_simple - fwd_ret_v_simple)` |

### 3.8 `benchmark_period_df`

- 生成位置：`scripts/run_single_factor.py::run_period_backtests`
- 母数据：`benchmark_target_df`
- 行索引：交易日期
- 生成逻辑：逐轨调用 `run_single_track_backtest(receiver="benchmark")` 后拼接
- 作用：基准侧单轨区间回测结果表

字段与 `strategy_period_df` 基本一致。主要区别是：

| 列 | 基准侧含义 |
|---|---|
| `signal_ls_raw` | 固定为 0 |
| `effective_signal_ls` | 固定为 0 |
| `post_trade_weight_g`, `post_trade_weight_v` | 由 `benchmark_mode` 决定，定期调回 0.5/0.5 或持有漂移权重 |
| `period_ret_ls` | 通常为 0，因为基准没有成长/价值方向信号 |

### 3.9 `daily_asset_ret_df`

- 生成位置：`scripts/run_single_factor.py::build_daily_asset_ret_df`
- 母数据：`data_df`
- 行索引：交易日期
- 作用：为逐日 NAV 重建提供成长/价值日频 simple return

| 列 | 含义 |
|---|---|
| `ret_g_daily_simple` | `close_g.pct_change()` |
| `ret_v_daily_simple` | `close_v.pct_change()` |

### 3.10 单轨 NAV 字典

## 5. 关键语义约束

| 主题 | 当前语义 |
|---|---|
| state 信号 | 每个调仓点重新判断；`signal_update_flag=1` |
| state 的 `NaN` / 阈值内 | 在 `build_state_target_position` 中落到 `signal_ls=0`、目标 50/50，后续由策略回测器引用基准仓位 |
| event 信号 | 只有事件触发时更新；无新事件为 `signal_update_flag=0` |
| event 的 `NaN` | 表示无新事件，不能简单视为中性 0 |
| `signal_ls=0` | 明确中性/跟随基准，不等于无信号 |
| `next_date` | 下一同轨调仓日期；最后若干行允许为 `NaT` |
| NAV 扣费时点 | 调仓日收盘后先扣本期费用，再按调仓后权重进入下一持有区间 |
| 五轨组合 NAV | 五条单轨 NAV 简单平均，只保留五轨都有净值的日期 |
